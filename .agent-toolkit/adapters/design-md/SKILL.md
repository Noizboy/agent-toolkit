# DESIGN.md adapter

This is a local Codex adapter for https://github.com/google-labs-code/design.md, not an upstream skill. Read the existing project DESIGN.md and the user's brief first. Locate the locked upstream source via .agent-toolkit/tools.lock.json (design-md source_path), then read README.md and only the relevant docs/examples.

Preserve established colors, typography, spacing, rounded corners, motion and component conventions unless a redesign is requested. Describe both exact tokens and rationale when creating DESIGN.md. Keep native/mobile/desktop platform constraints in the applicable sections. Do not manufacture brand context or modify DESIGN.md for backend-only work.

Check consistency with the real rendered interface. Coordinate with Interface-Agent; choose relevant impeccable, ui-ux-pro-max or taste guidance without combining conflicting aesthetic mandates. The user brief and existing project identity take precedence.
